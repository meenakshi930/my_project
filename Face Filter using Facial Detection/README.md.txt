# 🎭 Face Filter App (OpenCV Haar Cascades)

A real-time **Face Filter Application** using Python 3.13 and OpenCV.  
This project detects faces using Haar Cascades and overlays fun filters like glasses, crown, mask, dog ears, and mustache — no MediaPipe or dlib required.  

---

## ✅ Features
- ✅ Uses **Haar Cascades** (built into OpenCV) for face detection  
- ✅ Works with **Python 3.13**  
- ✅ **No MediaPipe** dependency (lightweight, easy to run)  
- ✅ Added **5 filters**:  
  - 👓 Glasses  
  - 👑 Crown  
  - 😷 Mask  
  - 🐶 Dog Ears  
  - 👨 Mustache  
- ✅ Better visual design with improved transparent PNG filters  
- ✅ User-friendly interface with simple keyboard controls
